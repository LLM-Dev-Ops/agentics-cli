# Diligence

Run due diligence analysis on references, vendors, or integration targets.

## Usage

- **Diligence**: `mcp__agentics-cli__agentics_diligence` with a `description`

## Examples

Run due diligence:
> Run due diligence on Acme Corp as a potential infrastructure vendor

Evaluate a technology:
> Due diligence on adopting Kubernetes for our production workloads
