# Inspect

Inspect resources, runs, and artifacts by ID or natural-language query. All read-only.

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `query` | Inspect a resource by natural-language query |
| `run` | Inspect a specific run by ID |
| `latest` | Inspect the most recent run |
| `artifacts` | List artifacts for a specific run |

## Usage

- **Query**: `mcp__agentics-cli__agentics_inspect_query` with a `query` string
- **Run**: `mcp__agentics-cli__agentics_inspect_run` with an `id`
- **Latest**: `mcp__agentics-cli__agentics_inspect_latest`
- **Artifacts**: `mcp__agentics-cli__agentics_inspect_artifacts` with an `id`

## Examples

Query a resource:
> Inspect the latest deployment to production

Inspect a run:
> Inspect run run-abc-123

See latest:
> Show me the most recent run

List artifacts:
> What artifacts were generated by run run-abc-123?
