# Login

Authenticate the CLI via browser-based auth or API key.

## Usage

- **Login**: `mcp__agentics-cli__agentics_login`
- **Login with key**: `mcp__agentics-cli__agentics_login` with `api_key` parameter

## Examples

Login:
> Log me into Agentics

Login with API key:
> Login with API key agentics_sk_xxx
