# Audit

Run comprehensive audit analysis on the current project or referenced resources.

## Usage

- **Audit**: `mcp__agentics-cli__agentics_audit` with an optional `description`

## Examples

Run an audit:
> Audit the current project for compliance issues

Audit with focus:
> Audit our infrastructure for SOC2 compliance gaps
