# Usage

Monitor token usage, costs, rate limits, and usage history.

## Subcommands

| Subcommand | Description |
|------------|-------------|
| (default) | Show current usage summary |
| `history` | Show usage history over time |
| `limits` | Show current usage limits and quotas |
| `reset` | Reset usage counters |

## Usage

- **Summary**: `mcp__agentics-cli__agentics_usage`
- **History**: `mcp__agentics-cli__agentics_usage_history`
- **Limits**: `mcp__agentics-cli__agentics_usage_limits`
- **Reset**: `mcp__agentics-cli__agentics_usage_reset`

## Examples

Check current usage:
> Show my current usage

View history:
> Show my usage history

Check limits:
> What are my current rate limits?
